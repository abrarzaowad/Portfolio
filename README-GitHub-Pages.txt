# Abrar Zaowad — Portfolio

Static portfolio website for GitHub Pages.

## Publish
1. Open https://github.com/abrarzaowad/Portfolio
2. Choose **Add file → Upload files**.
3. Upload `index.html`, the `assests` folder (including `abrar-zaowad.png`), and `.nojekyll` from this archive. Keep `index.html` at the repository root.
4. Commit the changes to the repository's default branch (usually `main`).
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then **Save**.
6. Wait for the Pages deployment to finish. The expected site URL is https://abrarzaowad.github.io/Portfolio/
